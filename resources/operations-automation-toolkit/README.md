## How to use the resources

1. Start with the outcome you need, not with a tool.
2. Adapt the template to your team's roles, systems and policies.
3. Assign a clear owner to each action and approval.
4. Keep records in an approved location with appropriate access controls.
5. Review the workflow after real use and improve it based on evidence.

Templates are starting points. They are not a substitute for an organisation's approved policies, professional advice, security controls or legal obligations.

## Responsible use

- Do not add passwords, API keys, confidential client records or sensitive personal information to public files.
- Do not paste confidential information into AI tools unless the organisation has approved that use and its safeguards.
- Verify AI-generated facts, names, dates, figures and recommendations.
- Test backups by restoring them; a successful export alone does not prove recoverability.
- Adapt WordPress maintenance steps to the site's hosting environment and recovery plan.

## Status and roadmap

This is an evolving public resource collection. Templates are available as individual Markdown or CSV files and can be adapted to suit a workflow.

Planned improvements include more role-specific checklists, examples of completed (fictional) workflows, clearer version history and feedback-driven revisions. No integrations, automated execution or hosted service are implied.
