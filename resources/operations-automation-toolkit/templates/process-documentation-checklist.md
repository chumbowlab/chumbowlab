# Process Documentation Checklist

Use this checklist before handing a recurring workflow to another person or team.

## Purpose and ownership

- [ ] State the outcome the process is meant to achieve.
- [ ] Identify the process owner and any approver.
- [ ] Define when the process starts and what counts as completion.

## Steps and hand-offs

- [ ] List the steps in the order they happen.
- [ ] Identify who is responsible for each step.
- [ ] Record inputs, outputs and expected timeframes.
- [ ] Explain what happens when information is missing or a step fails.
- [ ] Identify decisions, approvals and escalation points.

## Tools and information

- [ ] List the systems and documents required.
- [ ] Confirm access is granted only to authorised people.
- [ ] Do not include passwords, access tokens or secret keys.
- [ ] Avoid collecting personal or sensitive data unless necessary and authorised.
- [ ] Explain where the authoritative record is stored.

## Quality and maintenance

- [ ] Define how a completed task is checked.
- [ ] Add a last-reviewed date and document owner.
- [ ] Test the instructions with someone unfamiliar with the process.
- [ ] Record feedback and update the document when the workflow changes.
