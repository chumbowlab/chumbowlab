# Security

The repositories in this portfolio include prototypes and public workflow resources. They are not all production services and should not be assumed to provide enterprise security controls.

## Please do not

- Publish passwords, API keys, access tokens or private configuration.
- Upload personal, financial, tenant or client information to public issues.
- Use prototype applications to store sensitive or confidential records.
- Assume browser-local storage is encrypted, synchronised or backed up.

## Reporting a security concern

If you believe you have found a security issue in a project maintained here, please do not publish exploit details or sensitive data in a public issue.

Contact [Paul Chumbow by email](mailto:paulchumbow254@gmail.com?subject=Private%20security%20report) with:
- the affected repository and component;
- a concise description of the issue;
- safe reproduction steps, if available; and
- the potential impact.

Please allow reasonable time for review before publicly disclosing a vulnerability. This is a personal portfolio, so no formal security response-time guarantee is offered.

## Scope reminder

Prototype limitations are documented in each project's README. Do not use them as substitutes for systems with appropriate authentication, access control, secure storage, monitoring and tested recovery.
