# Follow-up Desk
### A small, local-first follow-up tracker

A lightweight browser tool for keeping track of people to get back to, outstanding commitments and the next action.

**Built by Paul Chumbow · Chumbow Lab**

## Open it

Open [index.html](./index.html) in a modern browser. No installation, build step, account or external library is required.

## Features

- Add and edit people, organisations, subjects and next actions.
- Record follow-up dates and status (Open, Waiting, Done).
- Search records and filter by status or overdue items.
- View open, waiting and overdue counts.
- Mark items complete or reopen them.
- Export records as CSV for use in spreadsheet applications.
- Responsive layout for desktop and mobile screens.

## Data and privacy

Records are stored in this browser using localStorage. They do not sync to another device or user and are not sent to a server. Clearing browser data may remove records. Export CSV regularly if you need a separate copy.

Use fictional or non-sensitive information. Do not store passwords, payment details, sensitive personal information or confidential client records in this prototype.

## Current limitations

- No login, cloud backup, shared workspace or multi-user access.
- No email, calendar or messaging integrations.
- No automatic reminders or notifications.
- CSV export is a file download, not a live spreadsheet connection.
